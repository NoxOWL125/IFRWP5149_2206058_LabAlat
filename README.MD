Praktikum Analisis & Desain Ber.Objek

Deskripsi
Praktikum ini bertujuan untuk mengidentifikasi kesalahan pada Use Case Diagram, menganalisis temuan, menentukan perbaikan beserta alasannya, dan membuat diagram yang benar sesuai aturan UML.

Tahapan Praktikum
1. Use Case Awal — Membuat diagram yang masih memiliki kesalahan.
2. Analisis Temuan — Mengidentifikasi kesalahan yang ditemukan.
3. Perbaikan — Menjelaskan solusi dan alasan perbaikan.
4. Use Case Akhir — Membuat diagram yang telah diperbaiki sesuai aturan UML.

Hasil
Praktikum menghasilkan Use Case Diagram yang telah diperbaiki berdasarkan hasil analisis dan aturan UML.
